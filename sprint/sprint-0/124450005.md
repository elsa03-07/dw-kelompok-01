## 1. Komponen saya

Saya bertanggung jawab pada komponen Profil dan Pembersihan Data bersama
Daffa Kharisma Adzana. Komponen ini berperan dalam memeriksa karakteristik data,
mengidentifikasi permasalahan kualitas data, serta melakukan pembersihan
agar data siap digunakan pada tahap pengolahan berikutnya.

Selain itu, saya juga terlibat dalam komponen Penjaga Data dan Evaluasi
untuk membantu memastikan hasil pengolahan data tetap konsisten dan
dapat dipertanggungjawabkan.

## 2. Keputusan wrangling

Pada Sprint 0, pekerjaan yang telah dilakukan masih berfokus pada
persiapan lingkungan kerja dan pengunduhan data. Saya telah mengunduh
data Kasus 07 (Partisipasi Pendidikan dan Lama Sekolah) sebanyak 15
berkas dan memastikan berkas tersebut sesuai dengan MANIFEST.csv.

Belum ada keputusan teknis pembersihan data yang saya tetapkan secara
mandiri. Keputusan terkait penanganan missing value, duplikasi, dan
ketidakkonsistenan data akan ditentukan setelah proses profiling
dilakukan.

## 3. Kegagalan dan pelajaran

Saat menjalankan `python pipeline.py`, proses mengalami kendala pada
tahap ekstraksi. Sistem menghasilkan `NotImplementedError` karena
pembaca format data pada direktori `src/ekstraksi/` belum
diimplementasikan.

Dari kendala tersebut, saya memahami bahwa setiap format data mentah
memerlukan pembaca yang sesuai sebelum dapat diproses lebih lanjut. Oleh
karena itu, implementasi pembaca data perlu diselesaikan terlebih dahulu
sebelum melanjutkan profiling dan pembersihan data.
